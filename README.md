# Random Team Picker

An application for assigning participants to random teams.

## Features

- Participant input
- Custom team count
- Randomized assignment

## How to Use

Enter participant names and select the number of teams.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Enter six names and generate two teams.
- [ ] Verify that each participant appears only once.
- [ ] Reject a team count exceeding participant count.
